# C Programming – Complete Beginner to Projects 🚀

Welcome to the **C Programming** section of **CS-Simplified**.

This repository is specially designed for students who are completely new to programming and want to learn C from the very basics in a simple and beginner-friendly way.

## 📌 About This Repository

Many C programming repositories and notes available on the internet assume that students already have some coding knowledge. However, this repository is different.

The notes provided here are created with the mindset of an average student who is learning programming for the first time.

These notes are:

✅ Beginner Friendly

✅ Written in simple language

✅ Easy to revise before exams

✅ Focused on concepts rather than memorization

✅ Handwritten and self-prepared notes

These notes are **not AI-generated notes**. They are based on my own learning journey, understanding, practice, mistakes, and experience while learning C Programming.

Every topic has been simplified so that even a student who has never written a single line of code can understand it comfortably.

# 🌟 Why I Created This Repository

When I started learning C Programming, I faced many difficulties.

Like many students, I spent countless hours searching for notes, videos, and explanations, but most of them felt difficult to understand.

As an average student, understanding programming concepts was not easy for me in the beginning.

After a lot of searching and learning from different resources, I finally found a playlist that helped me build my foundation in programming.

That playlist not only helped me understand C Programming but also helped me begin my coding journey.

I strongly believe that:

> Knowledge grows when it is shared.

Therefore, I decided to organize my notes, programs, and learning experience in a structured way so that other students can learn more easily than I did.
